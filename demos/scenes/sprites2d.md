# sprites2d

A side-scrolling parallax stack: three full-screen silhouette layers whose uv scrolls at 0.15, 0.4 and 0.8 of the
camera, plus 61 sprites floating at fixed screen positions in front of them, all as instanced quads from `shaders/sprite2d.vert` +
`shaders/sprite2d.frag`, alpha-blended back to front over a sky-blue clear. Conventions and `(verify)` meaning as in
pbr-boombox.md.

## Guest memory map

| VA | size | contents |
|---|---|---|
| 0x1000_0000 | 0x1_0000 | pushbuffer (init +0x0000, per frame +0x8000), GPFIFO ring +0xF000 |
| 0x1001_0000 | 0x1_0000 | shader heap: sprite2d.vert program +0x0000, sprite2d.frag program +0x8000 |
| 0x1002_0000 | 0x1_0000 | cbufs: VS c0 +0x0000, VS c1 +0x1000 (16 B), PS c0 +0x2000, PS c1 +0x3000 (16 B), PS c2 handles +0x4000 |
| 0x1003_0000 | 0x1_0000 | TIC pool +0x0000 (1 entry), TSC pool +0x8000 (1 entry) |
| 0x1010_0000 | 0x1_0000 | instance buffer, 64 x 48 B = 3072 B |
| 0x1020_0000 | 0x100_0000 | atlas, 2048x2048 RGBA8 pitch 8192, mip 0 only (16 MiB) |
| 0x1100_0000 | 0x39_0000 | colour target, 1280x720 A8B8G8R8 pitch 5120 |
| 0x1180_0000 | 0x1_0000 | frame report |

The atlas is generated by the host at init, so there is no asset file: rows 512k..512k+511 for k = 0, 1, 2 hold a hill
silhouette (opaque below a two-harmonic ridge of `(10 + 6k) * 8` texels with k + 1 periods across the row, transparent above,
colour darkening with k and towards the bottom); rows 1536..2047 hold four 512x512 sprite cells (disc, ring, star, diamond)
with alpha edges a few texels wide. Horizontal wrap is seamless because each ridge has a whole number of periods across 2048 texels.

## Instances (48 bytes each: transform, uv_rect, layer)

| instance | transform (cx, cy, hx, hy) px | uv_rect (u, v, du, dv) | layer (pos parallax, uv parallax, rotation, alpha) |
|---|---|---|---|
| 0 | 640, 520, 640, 200 | 0, 0.0, 3.0, 0.25 | 0, 0.15, 0, 1 |
| 1 | 640, 560, 640, 160 | 0, 0.25, 2.5, 0.25 | 0, 0.4, 0, 1 |
| 2 | 640, 620, 640, 100 | 0, 0.5, 2.0, 0.25 | 0, 0.8, 0, 1 |
| 3-63 | x = 40 + 21 n, y = 300 + 120 sin(n), h = 12-28 | cell (n mod 4) * 0.25, 0.75, 0.25, 0.25 | 0, 0, n * 0.37, 0.9 |

uv_rect heights of 0.25 select one atlas row; widths above 1 repeat the row across the screen through the wrap mode.

## Pools

TIC 0, the atlas: 0x58d24908 0x10200000 0x00400000 0x00000100 0x008007ff 0x800007ff 0 0 (A8B8G8R8 UNORM, verify).
TSC 0, repeat, linear, no mip: 0x00000000 0x00000062 0 0 0 0 0 0. Handle at PS c2 +0x0 = 0x00000000 (verify).

## Uniforms

VS c1: words 0-3 camera = (scroll x px, scroll y px, 2/1280 = 0x3acccccd, 2/720 = 0x3b360b61); per frame only word 0
changes (scroll x += 120 px/s), the rest is written once. PS c1: words 0-3 tint = (1, 1, 1, 1), written once.
Optionally the host spins the sprites by rewriting word 10 (layer.z) of instances 3-63 between frames, after the frame
report; the instance buffer is never written while a frame is in flight.

## Per-frame program (subchannel 0)

| # | method | offset | value | meaning |
|---|---|---|---|---|
| 1 | SET_CONSTANT_BUFFER_SELECTOR_A / B / C | 0x2380-0x2388 | 0x00000100 / 0 / 0x10021000 | select VS c1 |
| 2 | LOAD_CONSTANT_BUFFER_OFFSET / LOAD_CONSTANT_BUFFER (0) | 0x238c / 0x2390 | 0 / scroll x as f32 | camera scroll |
| 3 | CLEAR_SURFACE | 0x19d0 | 0x0000003c | clear RGBA to the sky colour |
| 4 | DRAW_VERTEX_ARRAY_BEGIN_END_INSTANCE_FIRST | 0x1214 | 0x50040000 | triangle strip, 4 vertices, instance 0 |
| 5 | DRAW_VERTEX_ARRAY_BEGIN_END_INSTANCE_SUBSEQUENT, non-incrementing packet of 63 | 0x1218 | 0x50040000 each | instances 1-63, drawn in order so layers stay behind sprites |
| 6 | SET_REPORT_SEMAPHORE_A / B / C / D | 0x1b00-0x1b0c | 0 / 0x11800000 / frame / 0x1000f010 | frame done |

## What the pipeline must provide

Per-instance vertex streams, alpha blending with separate alpha factors, repeat-wrap nearest sampling, and instance
order preserved when the FIRST + SUBSEQUENT draws are coalesced (blending makes order visible).
